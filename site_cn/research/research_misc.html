工控安全

工控安全（工业控制系统安全，ICS Security）是指保护生产现场的可编程逻辑控制器（PLC）、分布式控制系统（DCS）以及数据采集与监视控制系统（SCADA）等工业核心设备免受网络攻击与破坏。本实验室主要同SUTD合作，开展针对SWAT、EPIC等工控仿真系统的研究工作。
  1. Fan Zhang*, Qianmei Wu, Bohan Xuan, Yuqi Chen, Wei Lin, Christopher M. Poskitt, Jun Sun, Binbin Chen, "Constructing Cyber-Physical System Testing Suites Using Active Sensor Fuzzing," IEEE Transactions on Software Engineering (TSE), Vol.49, No.11, pp.4829-4845, 2023. [PDF]
  2. Yuqi Chen, Bohan Xuan, Christopher M. Poskitt, Jun Sun, Fan Zhang*, "Active Fuzzing for Testing and Securing Cyber-Physical Systems," Proceedings of the 29th ACM SIGSOFT International Symposium on Software Testing and Analysis (ISSTA), pp.14-26, 2020. [PDF]
  3. Yuqi Chen, Christopher M Poskitt, Jun Sun, Sridhar Adepu, Fan Zhang, "Learning-guided Network Fuzzing for Testing Cyber-Physical System Defences," 34th IEEE/ACM International Conference on Automated Software Engineering (ASE), pp.962-973, 2019. [PDF]
